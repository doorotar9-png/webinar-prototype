# Прототип вебинара

Здесь хранится статическая сборка сценария основного ведущего.
Исходный рабочий проект и инструменты разработки в этот репозиторий не входят.

Начальные состояния: подготовка, эфир, перерыв и завершение.
Действия симулируются в браузере; реальная трансляция и запись не выполняются.
Перезагрузка или сброс комнаты очищают изменения и загруженные изображения.

Сайт развёртывается через GitHub Actions. Источник в Settings → Pages — GitHub Actions.
